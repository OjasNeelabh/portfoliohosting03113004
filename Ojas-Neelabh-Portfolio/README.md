# Ojas Neelabh — Data Science Portfolio

A responsive personal portfolio website for Ojas Neelabh, a B.Tech Data Science student at MPSTME, Mumbai.

## Included
- Responsive dark/futuristic UI
- About section
- Three featured Data Science projects
- Skills section
- Contact section with no invented personal contact details
- Mobile navigation
- Scroll reveal animations
- No framework/build step required

## Run locally
Open `index.html` in a browser.

For the best local development experience, use VS Code with Live Server, or any simple static web server.

## Customize
Edit `index.html` for text/content and `style.css` for the visual design.

The project cards currently describe the planned portfolio projects:
1. Customer Churn Prediction
2. Retail Intelligence Dashboard
3. Sentiment Analysis

Replace/add GitHub and live-demo buttons after the corresponding projects are actually published.
